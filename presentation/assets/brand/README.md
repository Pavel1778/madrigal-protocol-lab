# Brand assets

The deck carries a neutral «Мадригал» wordmark generated from our own code
(`presentation/make_brand.py`): a dark plate with the name set in Tektur and the
brand accent bar. It reads as a deliberate client badge on both the dark and the
light deck and contains no third-party mark.

| File | Origin | Use |
| --- | --- | --- |
| `assets/madrigal-logo.png` | generated by `make_brand.py` | Title and closing slides |
| `assets/madrigal-mark.png` | generated by `make_brand.py` | Slide watermark, icon |
| `brand/texture-metal.webp` | `metallic` background asset | Neutral background |
| `brand/texture-metal-dark.webp` | `rust-2` background asset | Dark neutral background |
| `brand/texture-rust.webp` | `rust` background asset | Warm accent background |

The textures are abstract material images only. No portrait of a person from the
site is included, and the palette and typefaces the site ships with are recorded
in `docs/STYLE.md` under "Brand confirmation".
