## 11/10 — третий проход: воспроизводимая сборка

### Сборка

- `presentation/build_visualizations.py`: SVG пишутся без метки времени
  (`metadata={"Date": None}`), а хешированные `id`/`xlink:href` заменяются
  на последовательные (`x00000000`). Раньше пересборка переписывала все
  16 диаграмм из-за одного штампа даты; теперь повторная сборка — no-op
  (проверено `sha256sum` дважды подряд).
- `presentation/scripts/build_pptx.py`: `_freeze_zip()` пересобирает пакет
  с фиксированной датой записей (1980-01-01). `python-pptx` ставил время
  сборки в каждый part, поэтому `slides.pptx` менялся побайтово при каждом
  прогоне и ломал `checksums.txt`. Содержимое частей не меняется: два
  прогона дают один SHA-256.
- `presentation/presentation_html.zip` пересобран из чистого `dist/`
  (`rm -rf dist node_modules/.vite`): Vite держал в кеше старые диаграммы
  с меткой времени и хешем в имени файла, поэтому бандл содержал `-H36I5Huz.svg`
  вместо актуального. Теперь в архиве нет ни одного SVG с `dc:date`.
- `presentation/make_assets.py`: кадр постера выбирается по резкости
  (дисперсия лапласиана) из шести проб (5, 20, 40, 60, 90, 120 с) и в лог
  печатается выбранная секунда, а не зашитое «142».

### Артефакты

- `slides.pdf`, `slides-light.pdf`, `slides.pptx`, `presentation_html.zip`
  пересобраны; `checksums.txt` обновлён, `sha256sum -c` — OK на всех
  четырёх.
- Проверки после пересборки: `check_layout.py` — 0 проблем на обоих PDF,
