## 3. Imports, style, and types

`pyflakes` reported one unused `nonlocal` in `scripts/run_synthetic_stand.py`
(the variable was read but never assigned in `exchange`), and `ruff` reported
two unused imports in `tests/capture/test_export.py`. Removed.

`ruff check` found 31 findings. Fixed, grouped by kind:

- Annotation and import modernisation (`UP035`, `UP037`, `UP017`, `UP041`):
  quoted annotations removed, `collections.abc` imports, `datetime.UTC`, and
  `TimeoutError`. 25 applied automatically.
- Implicit string concatenation in collections (`ISC004`, 6): parentheses
  added, which is also what `ruff format` would do.
- Broad `except Exception` (`BLE001`, 3): these are deliberate. A torn pcapng
  record and an unreadable TCP checksum are reported as diagnostics or as an
  unknown field rather than a crash, matching the honesty rule. Each site now
  carries a `noqa` with the reason.
- Unparenthesised `and`/`or` chain (`RUF021`), `zip` without `strict`
  (`B905`, 2), and an unnecessary `"r"` mode (`UP015`). Fixed.

Three `mypy` errors, all real and fixed:

- `src/report/markdown.py`: `_version_lines` was annotated `list[str]` but
  returns a `str`; the wrong annotation, not the body, was at fault.
- `src/capture/reassembly.py`: the loop variable `physical` held an `int`, and
  an inner assignment reused the name for an `int | None` from
  `_physical_offset`, confusing the checker. Renamed to `source_offset`.

A `[tool.ruff]` and `[tool.mypy]` section was added to `pyproject.toml` so the
checks are reproducible. `E501` (line length) is off because `ruff format`
owns line wrapping; enabling both fights itself. `UP042` is off with a comment:
the `str, Enum` declarations are intentional so members compare as plain
strings in the public API.

## 6. Dependencies

`pip-audit` found one advisory: `PYSEC-2026-1845` in `pytest==8.3.4`, fixed in
`9.0.3`. The pin was raised to `9.0.3`; the full suite and coverage pass under
it. `ruff`, `mypy`, `pytest-cov`, and `pip-audit` were added to the `dev`
extra with pinned versions so CI installs the same tools locally.

`pip list --outdated` shows newer releases of `PySide6` (6.8.1 -> 6.12.0),
`jsonschema` (4.23.0 -> 4.26.0), and `PyYAML` (6.0.2 -> 6.0.3). These are left
at their pinned versions: the specification fixes the versions, and moving
`PySide6` across a minor line is not a change to make without a request.
