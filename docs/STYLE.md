# Style

## Palette

| Token            | Value     |
| ---------------- | --------- |
| Background       | `#131516` |
| Panel            | `#1D1D1D` |
| Light card       | `#E8E8E8` |
| Accent           | `#6D071F` |
| Accent gradient  | `#410913` → `#610D1C` → `#A2391D` |
| Text             | `#E0E0E0` |
| Secondary text   | `#9F9F9F` |

## Typography

- Headings: Tektur, weights Medium (500) and SemiBold (600).
- Body: Montserrat, weights Regular (400) and SemiBold (600).
- Line height: 1.3.
- Both fonts from Google Fonts, OFL licensed. Font files live in `assets/fonts/`.

## Geometry

- Corner radius: 4 px, at most 5 px.
- No pill buttons.
- No soft shadows.
- No gradients except the accent gradient.
- Dense modular grid.

## Rules

- No emoji.
- No exclamation marks.
- No friendly tone.
- Status colors (green / yellow / red) are used for statuses only, never as decoration.
- No jargon humor.
