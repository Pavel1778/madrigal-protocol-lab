## Решение

madrigal-protocol-lab — локальная настольная лаборатория для исследования
недокументированного бинарного протокола поверх TCP: она читает захват PCAP или
PCAPNG, восстанавливает каждый направленный поток с провенансом по каждому байту,
применяет декларативные правила интерпретации, проверяет их на корпусе, выявляя
контрпримеры, и записывает переносной проект с отчётом.

## Настройка

Python 3.12 или новее на Linux x86-64. Каждая команда выполняется офлайн.

```
python3 -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
```

## Запуск

| Задача | Команда |
| --- | --- |
| Тесты | `pytest tests/ -v` |
| Окно | `python -m src.ui.main_window --capture tests/corpus/reference_export/corpus_capture_01.normalized.json --rule examples/corpus_rule_v1.json` |
| Конвейер | `python -m src.project.cli pipeline --pcap tests/corpus/corpus_capture_01.pcapng --project project.madrigal --report reports/REPORT.md` |

## Демонстрация

Пошаговый проход по окну — в `docs/demo.md`. То же исследование из командной

## Что реализовано

| Область | Содержание |
| --- | --- |
| `src/capture/` | Чтение PCAP и PCAPNG, идентификация сессий, направленная сборка с диагностикой пропусков и неоднозначностей, провенанс по каждому байту, нормализованная выгрузка, CLI. |
| `src/hypothesis/` и `src/protocol/` | Стратегии фрейминга, декларативные правила, движок правил, проверка на корпусе и контрпримеры, движок альтернатив, версионирование правил, CLI. |
| `src/ui/` | Окно на PySide6: дерево сессий, hex-просмотр с провенансом, сравнение сообщений, панели правила и валидации, панель гипотез, сравнение версий. |
| `src/project/` | Переносное исследование на диске, относительные пути и sha256, экспорт и импорт zip. |
| `src/report/` | Исследование, отрисованное в Markdown и в самодостаточную HTML-страницу. |

## Где что лежит

| Путь | Содержание |
| --- | --- |
| `src/` | исходники |
| `docs/` | справка, контракты, схемы, аудит и этот файл |
| `presentation/` | презентация защиты и её снимки |

## Ограничения

| Область | Состояние |
| --- | --- |
| IPv6 | Поддержан; сессии, потоки и контрольные суммы ведут себя как для IPv4. |
| Фрагментация IP | Собирается для IPv4 и IPv6; неполная датаграмма сообщается, никогда не домысливается. |
| Зашифрованные нагрузки | Вне области; байты показываются как есть. |
| Контрольные суммы | По умолчанию выключены; перестановка трактуется как диагностика. |
| Меню проекта в окне | Есть: Новый, Открыть, Сохранить, Добавить захват, Сохранить версию правила, Экспорт и Импорт. CLI конвейера выполняет те же операции без окна. |
| Захваты организаторов | Получены и разобраны; закоммичены в `tests/corpus/real/`. Результаты — в `docs/REAL_CORPUS_ANALYSIS.md`. |
