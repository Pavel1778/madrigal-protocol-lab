# Русская документация

Русские версии документации проекта. Каждый файл в этом каталоге соответствует
английскому оригиналу в `docs/` или в корне репозитория; оригинал остаётся
источником правды, при расхождении верен он.

Русские документы дублируют английские для читателя-человека: участников,
заказчика и судей защиты. Код, комментарии, docstring'и и сообщения коммитов
остаются на английском.
