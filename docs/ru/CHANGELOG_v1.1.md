# v1.1.0 — фрагментация IP, заметки, связывание, 14-слайдовая дека

Английский оригинал: [CHANGELOG_v1.1.md](../../CHANGELOG_v1.1.md).

## Добавлено
- Пересборка фрагментов IP (IPv4 + IPv6, RFC 5722 для перекрытия)
- Заметки исследователя (хранятся в проекте)
- Связывание запроса и ответа с уверенностью и основанием
- Выгрузка разобранных сообщений в CSV / JSON Lines
- 19 типов полей (float, varint, TLV, bitmask, string, array, padding, checksum, computed, conditional)
- Выгрузка в Kaitai Struct + автономный парсер
- Выгрузка PCAP для Wireshark (--wireshark-pcap)
- Веб-интерфейс (FastAPI + HTMX)
- Тёмная/светлая тема + i18n RU/EN в GUI

## Изменено
- Регистрация правил: применённое правило теперь копируется в rules/ и индексируется в manifest.json (фикс R5)
- Спикерский сценарий защиты переписан под 14-слайдовую деку (маршруты на 5 и 10 минут)
- README: раздел обоснования стека, исправлены утверждения об IPv6/фрагментации
- DEFENSE_CHECKLIST: синхронизирован с фактическим числом тестов
- Презентация: брендинг Мадригала, полировка раскладки, типографика

## Исправлено

- Устаревшие счётчики тестов (781/806/838 → 849)
