# Стиль

Английский оригинал: [STYLE.md](../STYLE.md).

Окно берёт каждый цвет, шрифт и радиус из набора токенов, а не из констант,
разбросанных по коду виджетов. Токены живут в `src/ui/theme/`: `tokens.py`
задаёт имена полей, `dark.py` и `light.py` их заполняют, `manager.py`
переключает активный набор и применяет его заново. Смена темы — это подмена, без
перезапуска.

## Палитра — тёмная (по умолчанию)

Идентичность Мадригала: тёплый почти чёрный фон, один бордовый акцент.
Поверхности расслоены по глубине: слой, ближайший к читателю (меню, подсказки),
самый светлый, окно самое тёмное. Ни одна поверхность не чисто чёрная, и ни один
текст не чисто белый.

## Цвета статусов

Цвета статусов помечают вердикт и никогда не служат декором. У каждого набора есть
заливка (под байтами) и текстовый вариант для того же вердикта; светлый набор
использует светлые заливки с тёмным текстом, тёмный набор — приглушённые заливки
со светлым текстом. Имена: `status_matched`, `status_mismatched`,
`status_ambiguous`, `status_incomplete`, `status_uncovered`,
`status_not_applicable`, `status_outdated`, плюс `gap` и `hypothesis`. Зелёный,
жёлтый и красный появляются только через эти токены.

## Типографика

- Заголовки: Tektur, начертания Medium (500) и SemiBold (600).
- Текст: Montserrat, начертания Regular (400) и SemiBold (600).
- Моноширинный: `DejaVu Sans Mono` (`font_mono`), используется в hex-просмотре.
- Межстрочный интервал: 1.3.
- Оба отображаемых шрифта — с Google Fonts, под лицензией OFL; файлы `.ttf` и их
  лицензии лежат в `assets/fonts/`.

## Геометрия

- Скругление: 4 px (токен `radius`), максимум 5 px.
- Единица отступа: 4 px (токен `spacing_unit`).
- Без pill-кнопок.
- Без мягких теней.
- Без градиентов, кроме акцентного градиента.
- Плотная модульная сетка.

## Масштаб

- **Ctrl +** и **Ctrl −** меняют размер байта в пределах 8–28 px и двигают дерево
  на два пункта следом, чтобы они никогда не разъезжались; **Ctrl 0** возвращает
  значения по умолчанию (13 px байты, 11 px дерево). Шаги ограничены пределами, а
  пункты меню отключаются при достижении предела.

## Правила

- Без эмодзи.
- Без восклицательных знаков.
- Без «дружелюбного» тона.
- Цвета статусов используются только для статусов, никогда как декор.
- Гик-юмор не использовать.
