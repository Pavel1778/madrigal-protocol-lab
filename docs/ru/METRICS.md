# Метрики

Английский оригинал: [METRICS.md](../METRICS.md).

Числа для защиты. Каждое значение — из прогона, записанного в `docs/`, а не
оценка, кроме одной строки, помеченной как оценка. Источник каждой таблицы назван,
чтобы число можно было воспроизвести.

## Корпус

Счётчики из чтения каждого захвата движком захвата (`read_capture` /
`build_sessions`). Корпус создаётся `scripts/generate_corpus.py` и воспроизводим
из закоммиченных скриптов.

| Захват | Файл | Пакетов | Сессий | Роль |
| --- | --- | --- | --- | --- |
| corpus_capture_01.pcapng | 28.4 КиБ | 295 | 3 | основной; 280 сфреймленных сообщений, 140 запросов |
| corpus_capture_02.pcapng | 8.3 КиБ | 90 | 2 | отложен от фрейминга; используется для применимости |
| corpus_capture_defects.pcapng | 1.7 КиБ | 18 | 1 | ретрансмиссия, не по порядку, пропуск, конфликтующее перекрытие |
| synthetic_live.pcapng | 2.5 КиБ | 27 | 1 | настоящий стек TCP, другая раскладка; граница применимости |

## Устойчивость

Повреждённые и необычные захваты обрабатываются без неперехваченной ошибки; каждый
становится диагностикой или явно помеченной неизвестностью.

| Фикстура | Состояние |
| --- | --- |
| defects/fragmented_ip.pcap | фрагмент IP |
| defects/mixed_ip_versions.pcapng | IPv4 и IPv6 в одном файле |
| defects/mixed_link_types.pcapng | два типа канального уровня в одном файле |
| defects/truncated_header.pcapng | заголовок обрезан |
| defects/truncated_packet.pcapng | нагрузка обрезана |
| defects/unsupported_link_type.pcapng | тип канального уровня, которого парсер не знает |
| ipv6_mixed.pcapng | присутствует IPv6 |
| no_syn.pcapng | нет SYN, роли неизвестны |
| overlap_conflict.pcapng | конфликтующее перекрытие |

Захват дефектов (18 пакетов) нормализуется за 0.021 с обычным и 0.022 с потоковым
режимом, поэтому диагностики не ухудшают пропускную способность на этом размере.

## Ручное сравнение

| Подход | Время на 100 сообщений |
| --- | --- |
| Ручное чтение в hex-редакторе | 4–6 часов (оценка) |

прогон.
