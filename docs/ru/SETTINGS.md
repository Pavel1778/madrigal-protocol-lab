# Настройки

Английский оригинал: [SETTINGS.md](../SETTINGS.md).

Приложение хранит пользовательские предпочтения в `QSettings` под организацией
`madrigal`, приложением `protocol-lab`, сгруппированные в четыре раздела:
`general`, `editor`, `paths` и `advanced`. Окно читает их при запуске и применяет
на лету; ничего не пишется, пока пользователь не примет диалог.

Откройте диалог через **Вид → Настройки…** или сочетанием **Ctrl+,**.

## Общие

| Настройка | Значения | По умолчанию |
| --- | --- | --- |
| Тема | Тёмная, Светлая, Системная | Системная |
| Язык | Русский, English, Системный | Системный |

Тема и язык интерфейса применяются сразу после изменения, через те же
`ThemeManager` и `LanguageManager`, которыми пользуются меню. «Системная» следует
цветовой схеме рабочего стола и локали; палитры см. в `docs/STYLE.md`, а каталог —
в `src/ui/locale/`.

## Редактор

| Настройка | Диапазон | По умолчанию |
| --- | --- | --- |
| Размер шрифта hex | 6–48 px | 13 |
| Размер шрифта дерева | 6–48 px | 11 |
| Показывать колонку смещений | вкл / выкл | вкл |

Размер шрифта hex масштабирует сетку байт и её заголовок колонок вместе. Скрытие
колонки смещений убирает желоб адресов; колонки hex и ASCII сохраняют выравнивание,
а поиск байта по пакету продолжает работать.

Те же размеры достижимы без диалога: **Ctrl +** увеличивает, а **Ctrl −**
уменьшает байты и дерево вместе, **Ctrl 0** возвращает значения по умолчанию выше.
Клавиатурный масштаб меняет размер байта в пределах 8–28 px и держит дерево на два
пункта меньше, поэтому повторный масштаб не может развести их; диапазон диалога
остаётся шире для разовой тонкой подстройки. Оба пишут одни и те же ключи
`editor/hex_font_size` и `editor/tree_font_size`.

## Пути

| Настройка | Смысл | По умолчанию |
| --- | --- | --- |
| Каталог проектов | откуда начинаются диалоги сохранения | пусто |
| Каталог захватов | откуда начинаются диалоги открытия | пусто |
| Относительные пути в манифесте | хранить переносимые пути | вкл |

Настроенный каталог используется при первом открытии диалога файла. Как только
файл открыт или сохранён, его каталог запоминается до конца прогона и имеет
приоритет.

## Дополнительно

| Настройка | Значения | По умолчанию |
| --- | --- | --- |
| Уровень логирования | DEBUG, INFO, WARNING, ERROR | INFO |
| Показывать диагностики в интерфейсе | вкл / выкл | вкл |
| Показывать легенду состояний байтов | вкл / выкл | вкл |

Уровень логирования переконфигурирует корневой логгер. Выключение диагностик
скрывает заливку пропусков и неоднозначностей в hex-просмотре, чтобы сырые байты
читались без неё; сами диагностики остаются привязаны к потоку и достижимы через
строку провенанса. Выключение легенды состояний байтов скрывает полосу над
hex-просмотром, поясняющую заливку байтов.

## Кнопки

- **OK** применяет значения и закрывает.
- **Применить** применяет без закрытия, чтобы подстроить несколько разделов
  подряд.
- **Отмена** возвращает то, что было активно при открытии диалога, и закрывает без
  применения.

## Ключи хранилища

| Группа | Ключ | Тип |
| --- | --- | --- |
| general | `theme` | string |
| general | `language` | string |
| editor | `hex_font_size` | int |
| editor | `tree_font_size` | int |
| editor | `show_offset` | bool |
| paths | `project_dir` | string |
| paths | `capture_dir` | string |
| paths | `relative_paths` | bool |
| advanced | `log_level` | string |
| advanced | `show_diagnostics` | bool |
| advanced | `show_legend` | bool |

Значения по умолчанию объявлены один раз в `src/ui/settings.py`; сброс просто
очищает область настроек `madrigal/protocol-lab`.
