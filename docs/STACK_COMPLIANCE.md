# Соответствие технологическому стеку задания

Таблица «что требует задание → что используется → почему». Стек проверен
фактами: `pyshark` и `pandas` в исходном дереве не используются, собственный
hex-просмотр находится в `src/ui/hex_view.py`.

## Обязательные средства задания

| Пункт задания | Что у нас | Почему так |
| --- | --- | --- |
| Язык Python | Python 3.12+ (`requires-python = ">=3.12"`) | Требование задания |
| Графический интерфейс | PySide6 6.8.1 (Qt 6) | Задание требует локальное настольное приложение с окном |
| Обработка PCAP/PCAPNG | `dpkt` 1.9.8 | Читает оба формата напрямую, без `tshark`; даёт seq, флаги и сырые байты для точного реассемблинга |
| Хранение проекта | SQLite (`annotations.sqlite`) + JSON-манифест | Задание называет SQLite для аннотаций; манифест держит относительные пути и sha256 |
| Конфигурация правил | JSON + JSON Schema | Задание допускает JSON или YAML; выбран JSON как самый проверяемый |
| Командная строка для повторного применения | `src/protocol/cli.py`, `src/capture/cli.py` | R6: повторное применение без ручного описания каждого примера |

## Осознанные замены и почему

| Рассматривали | Взяли | Причина |
| --- | --- | --- |
| PyShark | `dpkt` | PyShark тянет внешний `tshark` и разбирает его текст: лишний процесс, потеря точности, завязка на Wireshark. `dpkt` — чистый Python, детерминирован, кладётся в Docker без `tshark` |
| pandas | собственный потоковый движок | Корпус читается потоком, весь набор в память не поднимается. Таблица pandas на 250k пакетов и 100k сообщений упирается в лимит 8 ГБ |
| готовый hex-виджет | `src/ui/hex_view.py` | Нужна связь «байт → пакет → поле → статус», которой у готового виджета нет |
| Wireshark как зависимость | Wireshark как эталон | Приложение работает без `tshark`; сравнение с `Follow TCP Stream` возможно через экспорт потока в отдельный PCAP |
| внешний движок интерпретации | декларативные правила JSON | Правило переносимо текстом, версионируется, проверяется схемой и повторно применяется из CLI |

## Что приложение не требует во время работы

- `tshark` и Wireshark — не нужны, только для независимой проверки.
- pandas — не нужен, движок собственный и потоковый.
- Сетевые сервисы — всё локально, офлайн.
- Макросы, плагины, внешние базы данных — не нужны.

